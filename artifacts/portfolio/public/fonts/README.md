# Self-hosted portfolio fonts
Downloaded 2026-11-20 from Google Fonts CSS and fonts.gstatic.com. Original families and normal/italic styles are retained; latin and latin-ext subsets are loaded on demand with font-display: swap. Chinese continues using the existing system-font fallback.
Google Fonts source repositories and licenses:
- https://github.com/google/fonts/tree/main/ofl/inter — inter-OFL.txt
- https://github.com/google/fonts/tree/main/ofl/playfairdisplay — playfairdisplay-OFL.txt
- https://github.com/google/fonts/tree/main/ofl/caveat — caveat-OFL.txt
Do not restore blocking third-party CSS imports. See src/styles/fonts.css for weight ranges and unicode coverage.
